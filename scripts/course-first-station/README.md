## 發生什麼事
舊 Google Sites 頁面（培訓文章後台／魔術方塊老師第一站）的內容，2026-06-03 曾被搬進
培訓平台的畫布式編輯器，但 (1) 畫布絕對定位在不同螢幕上跑版 (2) 內容被大幅刪節
（原始頁 249 行實質文字只搬了約 2 成，教學例句、八步驟詳解、通關密語等都遺失）。

2026-07-07 重做：直接從原始頁全文重新解析，重建為 8 課、41 個「直排卡片」區塊
（無畫布定位，排版響應式），並以逐元素比對驗證零遺漏（原始頁 324 個 DOM 元素，
扣除頁首尾導覽全數進入新版，含兩句給學員的通關密語彩蛋）。

## 還原方式（若需要）
用 anon key 對 `contents` 表：刪掉 8 個 lesson_id 底下的區塊，
把 `backup-old-111-blocks.json` 逐筆 POST 回去（保留原 id 欄位），
再依 `backup-old-lessons.json` PATCH 回 lessons 的標題與旗標。

## 注意
- 團隊卡片牆、按鈕群、作業說明框等區塊是手寫 HTML（flex 排版＋inline style）。
  **不要用後台的文字編輯器打開這些區塊重存**——quill 編輯器會把自訂 HTML 結構
  簡化掉。要改字請直接改資料庫或請 AI 改。
- 課程層級的 `is_published` 當時保持 false，由使用者確認後自行發布。

## 畫布復刻版的注意事項（2026-07-08）
- L0 頂部橫幅背景圖**直連 Google 圖床**（lh3.googleusercontent，公開可讀）；若日後
  Google Sites 該頁刪除，橫幅可能失效，屆時需把圖上傳到 Supabase Storage 再改該區塊。
- L2 的「三大群組總覽」長圖是 **data URI 內嵌 JPEG**（6 月上傳到 Storage 的版本裁錯了，
  把網站導覽列裁進去；原圖網址綁 Google 登入態無法直連）。
- 後台 CanvasEditor 可以開這些課編輯（就是標準畫布資料），但區塊數量多（每課 12～83 個），
  手動拖曳前建議先想清楚要動哪塊。
- 復刻是等比縮放：原頁內容寬 1154px → 畫布 960px，前台桌機再縮至約 848px 顯示，
  文字實際大小約為原頁的 74%。手機看畫布課程可用前台的「放大檢視」切換。
